# Projeto 1 — Busca e Ordenação

Módulos 1 e 2 em C++17, na pasta `modulo1`.

## Compilar e rodar

Dentro da pasta `modulo1`:

```powershell
g++ -O2 -std=c++17 -static src\*.cpp -o busca.exe
.\busca.exe
```

O programa lê `dados/filmesCrop.txt` e `dados/cinemas.txt`, então precisa ser executado de dentro de `modulo1`.
